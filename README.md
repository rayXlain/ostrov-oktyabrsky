# Остров Октябрьский — лендинг

## Что куда деплоить

Готовый сайт лежит в **`dist/`**. Это обычная статика: `index.html`, `styles.css`,
`app.js`, `assets/` и служебные файлы. Никакой сборки на стороне Netlify не нужно.

### Вариант 1 — перетащить папку (самый быстрый)

1. Открыть <https://app.netlify.com/drop>
2. Перетащить туда **папку `dist`** целиком (не её содержимое и не zip).
3. Netlify выдаст адрес вида `random-name-123.netlify.app` — его можно переименовать
   в настройках проекта (*Site configuration → Change site name*).

### Вариант 2 — через CLI

```bash
npx netlify-cli deploy --dir dist --prod
```

### После первого деплоя

В `build.mjs` наверху стоит `SITE_URL = 'https://ostrov-oktyabrsky.netlify.app'`.
Поменяйте на реальный адрес и пересоберите — иначе canonical, OG-картинка и
sitemap будут указывать не туда:

```bash
node build.mjs
```

## Структура

```
Остров Октябрьский.dc.html   исходник (артефакт, требует support.js) — правится он
support.js                   рантайм артефакта, в деплой не едет
assets/                      исходные изображения
src/                         то, что добавляется поверх исходника:
  styles.css                   оформление и анимации
  app.js                       вся интерактивность без зависимостей
  favicon.svg, 404.html, netlify.toml
build.mjs                    сборка: исходник + src → dist
dist/                        ← это и есть сайт для Netlify
export/                      старый самодостаточный файл (см. ниже)
```

Правим исходник или файлы в `src/` → `node build.mjs` → заново деплоим `dist/`.

## Что делает сборка

- вырезает обвязку артефакта (`<x-dc>`, `support.js`, `{{ }}`) — страница работает
  как обычный HTML;
- навешивает классы и хуки анимации на существующую разметку;
- проставляет картинкам `width`/`height` и `loading="lazy"`, первому экрану —
  `fetchpriority="high"` (меньше сдвигов вёрстки, быстрее первый экран);
- собирает `<head>`: title, description, canonical, Open Graph, Twitter Card,
  JSON-LD, иконки, `robots.txt`, `sitemap.xml`;
- добавляет `?v=<хэш>` к CSS и JS, поэтому в `netlify.toml` они кэшируются на год,
  а HTML — всегда свежий;
- копирует только те изображения, что реально есть на странице.

## Анимации

| Что | Где |
| --- | --- |
| Штора первого экрана, посадка заголовка построчно, медленный наезд кадра | `.hero-media`, `.hero-body` в `styles.css` |
| Параллакс фото + лёгкий сдвиг героя за курсором | `tick()` в `app.js` |
| Появление блоков при скролле с «лесенкой» по соседям | `[data-reveal]`, `--rd` |
| Фото открываются шторой + отъезд масштаба, приближение по наведению | `[data-reveal-img]` |
| Счётчики (10, 50, 80, 2, 3/2/5) набегают с нуля | `countUp()` |
| Шапка прячется при скролле вниз, рейка объектов подъезжает к верху | `.site-header`, `--rail-top` |
| Подсветка активного объекта в рейке и пункта меню | `[data-spy]`, `.nav-link.is-current` |
| Хронология тянется мышью, карточки выезжают сбоку | `.timeline-scroller`, `[data-reveal-x]` |
| Переключение RU/EN с плавной подменой текста, язык запоминается | `switchLang()` |
| Зерно поверх страницы | `body::after` |

Всё это выключается системной настройкой «уменьшить движение»
(`prefers-reduced-motion`) — контент показывается сразу и без сдвигов.
Если `app.js` почему-то не загрузится, через 2.5 секунды страница
покажет весь контент принудительно (класс `reveal-all`).

## Пасхалка

В самом низу, в футере, — почти невидимая точка. Клик по ней (или код Konami:
↑↑↓↓←→←→BA) показывает «Аркаша лох, объелся блох» и семь скачущих блох.
Повторный клик по точке закрывает. В консоли — подсказка, где искать.

## Как посмотреть локально

```bash
cd dist && python -m http.server 8765
```

затем <http://localhost:8765>. Прямое открытие `index.html` двойным кликом тоже
работает, но часть браузеров ограничивает локальные файлы — сервером надёжнее.

## Что осталось сделать при желании

- **Вес картинок.** 5,9 МБ на 28 файлов; всё грузится лениво, но если прогнать
  их через WebP/сжатие (`squoosh`, `sharp`), станет заметно легче.
- **Герой.** `assets/bolshoy-01.jpg` — всего 640×429, на большом мониторе мягковат.
  Если найдётся версия побольше, положить её вместо этого файла.
- **Права на материалы.** Фото и визуализации: Калининград.Ru, «Стройтрансгаз»,
  gk-gorka.ru, презентации застройщиков. Для публичного сайта использование нужно
  согласовать с правообладателями.

## Старый экспорт

`export/ostrov-oktyabrsky-standalone.html` — самодостаточный файл на 8,7 МБ
(картинки и шрифты вшиты внутрь), который был сделан раньше. Он **не содержит**
новых анимаций и меты. Удобен, чтобы отправить одним файлом; для сайта —
используйте `dist/`.
